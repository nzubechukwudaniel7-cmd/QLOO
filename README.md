# NeuroTaste — Autonomous AI Caregiving Agent

> **Qloo Agentic Hackathon 2026 Submission**  
> *Transforming fragmented youth memories into personalized, non-pharmacological sensory de-escalation protocols for dementia care — powered strictly by Qloo's 250M+ Taste Graph and passive contactless optical rPPG biofeedback.*

---

## Executive Summary

Over 55 million people worldwide suffer from Alzheimer's and related dementias. Between 4:00 PM and 8:00 PM daily, up to 66% experience **Sundowning Syndrome** — extreme neuropsychiatric distress marked by anxiety, pacing, repetitive crying, and aggression.

Historically, facilities resort to chemical restraints (antipsychotics/sedatives) despite FDA Black Box warnings and federal penalties. Under **CMS F-Tag 758 (42 CFR § 483.45(e))**, long-term care facilities are federally mandated to exhaust documented non-pharmacological interventions before administering psychotropic drugs.

**NeuroTaste** is an autonomous bedside clinical agent that solves this dilemma:
1. **Zero-Touch Optical Biofeedback:** Uses webcam-based remote photoplethysmography (rPPG) measuring micro-vascular green-channel light absorption on the resident's face to track real heart rate and heart rate variability (HRV) without distressing wires or cuffs.
2. **Qloo Taste Graph Personalization:** Resolves fragmented youth memories (artists, movies, hometown flavors, cultural anchors) into multi-sensory de-escalation protocols spanning 4 therapeutic pillars.
3. **Dynamic In-Session Recalibration:** Closed-loop biofeedback recalibrates protocols in real time if agitation spikes.
4. **Automated Federal CMS Audit Records:** Produces exportable compliance certificates satisfying federal inspectors.

---

## 4-Pillar Sensory De-Escalation Engine

Every protocol generated by NeuroTaste is mapped to four therapeutic pillars grounded in clinical reminiscence therapy and Qloo Taste Graph affinities:

1. **Auditory Pillar (Music Therapy):** Deep-catalog musical anchors matched to the resident's youth (1940s–1970s), filtered by acoustic traits to avoid sudden brass agitation.
2. **Visual Reassurance Pillar:** Era-authentic cinematic film clips, archival hometown streetscapes, and familiar architectural aesthetics to anchor spatial orientation.
3. **Culinary & Olfactory Grounding:** Taste and scent anchors invoking episodic memory (e.g., Chicago deep-dish aromas, vanilla bean, vintage bakery scents).
4. **Verbal Validation Scripts:** Person-centered conversational scripts for bedside caregivers to de-escalate anxiety without confrontational reality orientation.

## Key Features

- **Full 3D WebGL Neural Cortex:** Real-time 3D particle brain simulation (2,600+ particles, spherical harmonics, gyri/sulci folding, dynamic synaptic lines, mouse parallax tilt) powered by Three.js.
- **100% Real Optical rPPG DSP:** Native browser pixel sampling with `willReadFrequently: true`, DC detrending, low-pass FIR filtering, inter-beat interval (IBI) calculation, and real BPM/RMSSD telemetry.
- **Direct Web Bluetooth GATT:** Connects to BLE heart rate monitors (Polar, Garmin, smartbands) without external drivers.
- **Strict Qloo Developer Cloud Integration:** Every entity is resolved against `https://hackathon.api.qloo.com` with entity IDs, affinity ratings, and latency tracking.
- **CMS F-Tag 758 Federal Compliance Audit Generator:** One-click generation of immutable clinical compliance certificates documenting non-pharmacological interventions.

## Quickstart & Installation

### 1. Prerequisites
- Python 3.10+
- Modern Web Browser (Chrome, Edge, Firefox, Safari) with WebGL and Camera access

### 2. Setup Environment
```bash
# Clone the repository
git clone https://github.com/nzubechukwudaniel7-cmd/QLOO.git
cd QLOO

# Install dependencies
pip install -r requirements.txt

# Configure your Qloo API Key
cp .env.example .env
# Edit .env and enter your QLOO_API_KEY
```

### 3. Run NeuroTaste
```bash
python run.py
```
Or double-click `START_NEUROTASTE.bat` on Windows.

### 4. Access the Application
- **Public Product Showcase & 3D Brain:** [http://localhost:8000/](http://localhost:8000/)
- **Clinical Caregiver Console:** [http://localhost:8000/app](http://localhost:8000/app)
- **Interactive OpenAPI Documentation:** [http://localhost:8000/docs](http://localhost:8000/docs)
